# 姿态驱动的闪念胶囊界面与功能闭环

**Status:** in progress
**Priority:** high

## What this is for

当前固件已有姿态计时、KEY2 录音和 LVGL 状态页，但屏幕交互、蓝牙遥控、多条录音持久化仍未形成产品闭环。目标是让设备根据稳定姿态切换到对应的可操作界面，并把计时、录音和遥控实际接到触摸屏、扬声器、TF 卡和电脑。

## What it does

- **视口边界与容器去装饰：** 只在 450×390（物理 390×450 旋转 270°）屏幕内绘制 `design.html` `#amoled-viewport` 内的四个核心界面，不包含 HTML 原型外围的姿态切换栏、陶瓷外壳框、虚拟 KEY2 / CARD 按钮与底部硬件状态栏。根屏幕、3×3 姿态画布 `ui_page` 与四个姿态面板均清零 `border_width`、`radius`、`outline_width`、`pad_all` 并禁用滚动条，消除 LVGL 默认主题带来的边缘横线与偏移；移除顶层调试用的 `WAITING FOR POSE` 标签。
- **全局双主题（微晶亮色 / 暗夜护眼）：** 内置与 `design.html` 对齐的亮色/暗色两套配色令牌（屏幕底色、内凹显示屏 `recessed`、普通陶瓷键、主色高亮键、危险红键、胶囊描边与三级文本色）。在 `TIME` 子页点击月亮键即实时切换全局四页面的亮/暗主题，状态保存在 RAM 中。
- **直立姿态（STAND）三模式中心（`POMO` / `TIME` / `STOPWATCH`）：**
  - 顶部居中展示三项分段药丸切换栏（`POMO`、`TIME`、`STOPWATCH`），支持点击药丸切换，也支持在直立页面内容区左右滑动屏幕（水平位移阈值 > 40 px）平顺切换子模式。
  - **默认与记忆：** 开机默认处于 `TIME`（桌面时钟）子页；所选子模式保存在 RAM 中，切换到侧放/放平/扣下后再回到直立姿态时，仍停留在上次选择的子模式。
  - **子模式 A：`POMO`（番茄钟）：** 内凹卡片居中显示大号倒计时（`MM:SS` 或 `MMM:SS`，支持 1–120 分钟，默认 25 分钟）、右侧独立锚定的响铃开关按钮（`BEEP`）以及底部状态指示点与状态文本（`READY` / `RUNNING` / `PAUSED` / `COMPLETED` / `RESET`）。底部四键为 `[ - ]`、`[ ↺ 复位 ]`、`[ ▶/⏸ 启停 ]`、`[ + ]`。短按 `-`/`+` 调整 1 分钟，长按 ≥500 ms 阶梯加速连续调节（250/120/60 ms）；点击 `↺` 复位为当前预设时长并回到待机；点击 `▶/⏸` 手动开始或暂停。离开直立姿态时自动暂停；回到直立姿态时，仅当当前子模式为 `POMO`（或计时器处于运行/暂停恢复流且在 `POMO` 页）才自动开始/继续倒计时，停留在 `TIME` 或 `STOPWATCH` 子页立起时不后台偷跑番茄钟。到期时按 `BEEP` 开关异步播放 500 ms 提示音。
  - **子模式 B：`TIME`（桌面时钟）：** 读取片上 RTC（`time()` / `localtime()`，支持 MSH `date` 命令校时）实时显示当前时间与星期日期（`DOW · MON DD`）。大号小时分钟数字（`HH:MM`）独占水平居中；开启秒显示时，`:SS` 挂在主数字右侧同基线位置；12 小时制下 `AM`/`PM` 挂在右上角作上标（秒开启时自动右移让位），切换时不推动主数字中心。底部三键为 `[ 12H/24H 切换 ]`、`[ 秒显示开关 ]`、`[ 暗夜模式切换 ]`。
  - **子模式 C：`STOPWATCH`（正向秒表）：** 内凹卡片居中显示 `MM:SS.d`（0.1 秒精度）跑秒与最近计次胶囊条（未计次显示 `NO LAP`，计次后最新 `LAP N · MM:SS.d` 胶囊置前展示）。底部三键为 `[ ↺ 复位 ]`、`[ ▶/⏸ 启停 ]`、`[ ⚑ 计次 ]`。
- **左/右侧放姿态（SIDE_LEFT / SIDE_RIGHT）多媒体遥控页：** 左右侧放界面布局一致。顶栏左侧显示 `DESK·02` 标识，右侧显示蓝牙状态胶囊（已连接高亮 `CONNECTED`，未连接置灰显示 `OFFLINE`）；中部为 3 行 2 列共 6 个大尺寸圆角按钮：`[ VOL - ]`、`[ VOL + ]`、`[ PREV ]`、`[ NEXT ]`、`[ MUTE ]`、`[ PLAY/PAUSE（主色高亮）]`；底栏显示即时操作反馈（如 `VOL + TRIGGERED`、`MUTED`，1.5 秒后恢复 `MEDIA CONTROLLER` 或 `BLUETOOTH DISCONNECTED`）。未连接 BLE 时 6 个按钮呈现禁用态反馈。保留实体 KEY2 侧放短按（左 VOL+、右 NEXT）与长按（系统静音）宏语义，以及免密 Just Works 配对绑定。
- **放平姿态（FLAT）语音便签页：**
  - 上方内凹卡片顶部左侧显示当前文件名（如 `MEMO_0001.WAV`、录音中 `RECORDING...`、无卡 `MEMO_RAM.WAV` 或错误提示），顶部右侧显示含 7 根竖条的胶囊波形指示器（待机静态低矮，录音或回放时动态起伏跳动，录音态变红）；中部左侧显示大号当前时长 `00:SS`，右侧显示上限 `00:30`；底部为带圆点滑块的圆角胶囊进度条（0–100% 实时展示录制或 WAV 回放提交进度，只读不跳播）。
  - 下方四键操作栏：`[ 文件夹切换（TF 在线主色高亮 / RAM 模式普通态）]`、`[ ▶/■ 播放/停止 ]`、`[ ● 录音/停止（内置双圆环图标，录音态切换危险红）]`、`[ 🗑 删除（首次点击变危险红 CONFIRM?，再次点击执行删除）]`。切换文件、开始录音或离开放平姿态时自动取消删除确认。
- **实体键 KEY2 与姿态转场：**
  - KEY2 保持硬件全局闪念语义：录音中任意姿态按下立即停止录音；桌面侧放姿态下短按/长按发送 BLE 多媒体宏；直立或放平姿态下按下开始/停止录音。
  - 姿态连续稳定 400 ms 触发切页；4 个姿态页面以 260 ms ease-out 滑动转场，途中出现新稳定姿态时从当前位置连续转向最新目标；未知姿态保持当前页面；扣下（`FACE_DOWN`）关闭背光熄屏并静音，恢复已知姿态后点亮并滑向目标页。

## How it is built

- `capsule/` 承载可主机测试的姿态防抖、番茄钟启停/复位/调时、KEY2 宏和录音 WAV 封装状态机；提供手动启停/复位与按直立子模式控制自动恢复的接口，不直接依赖 LVGL 或硬件驱动。
- `project/proj.conf` 开启 `CONFIG_LV_FONT_MONTSERRAT_48=y`，配合既有 14/16/20/24/28/36 字号构成与原型对应的字号层级；图标采用 LVGL 内置符号（`LV_SYMBOL_*`）与原生 `lv_obj` 几何组合（如双圆环录音键、7 柱波形条、胶囊进度条），不引入外部位图资产。
- `src/main.c` 实现双主题样式表（`ui_theme_apply(bool dark)`）、无边框全画布 3×3 姿态容器、直立三子模式横向轨道与触摸滑动手势检测（区分按钮点击与 >40 px 横滑）、RTC 时钟读取（`time`/`localtime`）与 100 ms 秒表计时器，并通过 `ui_command_queue` 串行分发触控命令。
- 在不改变官方传感器 PA40/PA39 与触摸 PA33/PA37 引脚用途的前提下保持 I2C1 互斥访问与 270° 旋转触摸坐标映射。
- TF 录音库（`src/tf_library.c`）与 BLE HID（`src/ble_hid.c`）保持既有存储、回放（增加播放中再次点击停止回放标志）与 Consumer Control 报告能力。
- 更新相关设计/测试文档，如实区分主机测试、固件编译与真机手动验收。

## What it must not do

- 不将 `design.html` 外部模拟器控件（顶部姿态选择栏、陶瓷外壳边框、虚拟 KEY2 / CARD 按钮、底部硬件状态栏）绘制进板端屏幕。
- 不实现语音转写、云同步、电池休眠、自动专注/休息循环、录音进度条点击跳播（seek）、屏幕时钟校时弹窗或神经网络 VAD。
- 不把系统音频静音描述为麦克风静音。
- 不以主机测试或固件编译代替触摸、TF 卡、扬声器和 HID 的真机验收。

## What was considered and rejected

- **只要立起就无条件自动开始番茄钟。** 虽与旧固件一致，但在直立默认进入 `TIME` 桌面时钟后，用户仅看时间也会后台跑完番茄钟并触发蜂鸣；改为仅当直立子模式处于 `POMO`（或已手动启动）时立起自动运行。
- **把 SVG 图标与特大字号转成位图/自定义字库资源。** 虽能像素级复刻矢量曲线，但占用额外 Flash 且无法随亮色/暗夜双主题零成本变色；改用 `lv_font_montserrat_48` + LVGL 内置符号与原生几何控件。

## Verification policy

开发阶段以实现规格要求为主，不做无意义、重复或过多的测试，也不做冒烟测试。各功能任务完成后不单独执行测试；全部本 effort 的规格与实现任务完成后，由用户统一进行真机手动验收。开发记录应如实注明尚未验证，不得把未测行为写成通过。

## How we will know it works

- **W1.** 直立姿态默认进入 `TIME` 桌面时钟，顶部分段栏与左右滑动手势可在 `POMO` / `TIME` / `STOPWATCH` 三子模式间切换并在 RAM 中记忆，切换其他姿态再立起时保持原选择；`TIME` 支持 12H/24H、秒显示开关和全局亮/暗主题切换；`STOPWATCH` 支持启停、复位与计次胶囊；`POMO` 支持 `[- / ↺ / ▶⏸ / +]` 四键、BEEP 开关、仅在 `POMO` 子页立起自动运行/离开暂停，到期时扬声器实际响。
- **W2.** 450×390 全画布无默认主题残留边框或边缘横线，亮/暗两套主题在四页面全部生效；稳定姿态 260 ms 平滑切换页面；快速换姿态时动画跟随最新目标；未知姿态不闪页；扣下熄屏、恢复显示；IMU 采样持续正常。
- **W3.** 平放语音便签页还原文件名、7 柱动态波形、时长/`00:30`、只读胶囊进度条与底部四键；手动或 KEY2 录音每秒更新时长与波形，停止后显示最终时长；点击播放显示实时进度与动态波形，播放中再次点击可停止；插 TF 卡支持切换、播放、二次确认（`CONFIRM?`）删除，无卡时回退 RAM 录音。
- **W4.** 用户可从手机或电脑蓝牙设置发现 `POMO_MEMO_HID` 并免密配对；音量加/减、静音、上一曲、播放/暂停、下一曲均能控制主机，断开重连后仍生效。
- **W5.** 左右侧放多媒体控制页一致展示 `DESK·02`、蓝牙连接状态胶囊（`CONNECTED` / `OFFLINE`）、3×2 图标按钮与底部即时操作提示；未连接时按钮显示禁用态；姿态/触摸并发期间无重复 I2C 错误。
- **W6.** 更新测试报告，区分 SDK 构建、主机逻辑测试和真实板端结果；未实际执行的触摸、扬声器、TF、配对和按键检查标为待验收。

## Risks

- TF 卡为自备件；若没有可用卡，W3 的持久化、掉电保留、卡满与真机删除验收无法完成。
- 屏幕触摸与 IMU 共用 I2C1；必须在真机上确认 SDK 总线访问串行化有效，不能通过改坏 IMU pinmux 来规避。
- SDK 的 BLE HID、TF/SPI MSD 与文件系统配置需在本机 v2.5.1 板型上实际构建和验证；示例可用不等于本项目配置已验证。
