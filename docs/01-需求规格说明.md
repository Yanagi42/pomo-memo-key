## 1. 引言

### 1.1 目的与范围

本文描述「闪念胶囊」本期要做和明确不做的事。它是放在桌上的番茄钟，也是不用看屏幕就能按一下录音的便签。

本期做：直立开始 25 分钟倒计时；扣下暂停并且不响结束提示；KEY2 录音，停录后去掉长段静音，留下 16 kHz 单声道 WAV；在桌上侧放时，同一个键改发宏事件。宏只做到事件，不做到电脑真的变音量。

本期不做：TF 卡落盘、蓝牙 HID、蓝牙传文件、转写和大模型待办、神经网络 VAD、外壳。这些保留编号，不从需求里删掉。

### 1.2 术语与缩写

| 术语 | 含义 |
|---|---|
| 直立 / 扣下 / 平放 / 左侧 / 右侧 | 五个要标定的静止姿态 |
| 未知 | 合加速度不像静止重力，或和两个参照都太接近 |
| 桌上 | 出现过直立、平放或扣下之后的一段状态。稳定未知满 3 秒后取消 |
| 宏事件 | 音量加、下一首、麦克风静音。只有类型和递增序号 |

## 2. 产品概述

### 2.1 一句话定位

给自己用的桌面番茄钟。立起来开始计时，扣下去就安静；想记一句时按一下，不用先开屏幕。

### 2.2 目标用户与使用场景

- 目标用户：做这个作业的人自己。
- 典型场景 1：桌上 USB 供电。把板子立住，计时 25 分钟。扣下时暂停，结束提示不响。
- 典型场景 2：侧放在桌上当宏键盘。左侧短按音量加，右侧短按下一首，长按麦克风静音。
- 典型场景 3：拿起来按 KEY2 录音。松手不算结束，再按一次停止。口袋场景要自备电池，本期不依赖电池和 TF 卡。

### 2.3 核心痛点与现有方案

| 现有方案 | 优点 | 不足 | 本产品的差异点 |
|---|---|---|---|
| 手机番茄钟 | 现成 | 要看屏幕、解锁 | 立起即开始，扣下即暂停 |
| 手机备忘录 | 能转文字 | 要先点开应用 | 一个键开始录音，停录后去掉长静音 |
| 小智语音助手 | 板上已经有录音和蓝牙 | 整条链路是对话助手，不是番茄钟 | 本期只取板级事实，不把小智产品搬进来 |

## 4. 非功能需求

| 需求ID | 类别 | 描述 | 验收标准 |
|---|---|---|---|
| REQ-101 | 时序 | 姿态采样周期不超过 400 ms，建议 100 ms。超过 400 ms 时稳定窗口重头计 | 周期设成 500 ms 时直立不会稳定，倒计时不开始 |
| REQ-102 | 接口 | 加速度用 `capsule_accel_millig`。±2 g，`round(raw * 61 / 1000)`，单位毫 g | 16384 换成 999，-16384 换成 -999 |
| REQ-103 | 存储 | 五个参照导出为 64 字节，魔数 `CPM1`。全零槽表示未标定。其它值若不是静止重力，导入失败且不改原表。导入放在 `capsule_init` 之后 | 短缓冲导出返回 0。坏魔数或坏槽导入后，原参照还在 |
| REQ-104 | 资源 | PCM 与 WAV 缓冲按 2 字节对齐。逻辑不要放进中断。裁剪标记约 4 KB 放静态区。30 秒 PCM 约 960 KB 放 PSRAM。录音任务栈建议不小于 8 KB | 奇数地址的 WAV 缓冲在初始化时失败。样本数为 0 不写文件 |

## 5. 硬件约束与接口核对

- [x] 屏幕：1.85 寸 AMOLED 390×450 触摸。本期界面还没画。
- [x] 传感器：六轴 LSM6DS3TR-C，地址 0x6A。姿态只用加速度。地磁和环境光本期不用。
- [x] 音频：板载 MEMS 麦克风。喇叭只插丝印 SPK。
- [x] 无线：蓝牙 5.3 在板上，本期不用。无 WiFi。
- [x] 交互：KEY1 为 PA34，不用作录音键。KEY2 为 PA43，课程示例里按下为高，本期功能键。小智移植把 PA43 当作休眠唤醒，那是它的开关机策略，本期桌面 USB 供电，不照搬。板上有 RGB 灯，本期不用来表达产品状态。
- [x] 存储：TF 卡槽在，卡要自备。本期录音在内存里，掉电就没了。
- 需要额外采购/焊接的部件：口袋使用要自备电池。TF 卡、振动马达都不在本期。
