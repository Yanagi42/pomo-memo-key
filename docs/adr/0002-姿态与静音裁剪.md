# ADR-0002: 用标定向量判断姿态

- 状态：姿态决策保留；录音静音裁剪决策已由用户于 2026-11-06 取代
- 日期：2026-11-01；录音处理更新：2026-11-06
- 决策人：待填写　协助：Grok
- 关联需求：REQ-001、REQ-002、REQ-004、REQ-102、REQ-205

## 背景

外壳如果有倾角，就不能假设某一根轴垂直于屏幕。芯片资料提到神经网络加速器，但没有能直接当 VAD 用的示例。

## 备选方案

| 方案 | 优点 | 缺点 | 对需求/风险的影响 |
|---|---|---|---|
| A. 写死 X/Y/Z 的朝向 | 不用标定 | 外壳一变就错 | REQ-001 无法在未知外壳上成立 |
| B. 五个静止姿态各记一个加速度，用方向相似判断 | 不依赖轴的命名 | 第一次使用要摆五个姿势 | 标定要能跨掉电保存 |
| C. 片内神经网络做 VAD | 可能更能分开人声和噪声 | 没有模型、输入格式和时延数据 | REQ-205 留到以后 |
| D. 按帧去掉直流后比能量 | 主机上就能测，门限能改 | 轻声可能被裁掉，持续噪声可能留下 | 满足本期“静音变短” |

## 决策

姿态选择 **B**：五个静止姿态分别标定加速度向量，按方向相似度判断。

原先对录音选择 **D**，按能量裁剪静音；用户于 2026-11-06 明确决定不做任何静音检测或裁剪，手动停止时保留完整 PCM。本期实施以该用户决定为准。

## 后果

- 姿态参照可导出成 64 字节；两个参照太接近时结果为未知，计时不会乱跳，但需重新标定。
- 录音停止时完整写 WAV；代码中不保留静音裁剪实现。
- 相关实现：`capsule/src/pose.c`、`capsule/src/capsule.c` 和录音用例。
