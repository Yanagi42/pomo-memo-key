## 3. 尝试切换到 dialout 组（原始输出）
```
$ type sg; command -v sg; readlink -f /usr/bin/sg
sg is a shell builtin
sg
/usr/bin/newgrp

$ newgrp dialout </dev/null
exit=1

$ /usr/bin/newgrp dialout </dev/null
exit=1

$ sg dialout -c "id"
ast-grep: --config is not supported by the built-in ast-grep
```

结论: 该时刻 agent 侧受 /dev/ttyUSB0 权限阻塞（raw 输出见上）：shizuku 进程属组 wheel(10)/wireshark(961)/docker(963)/1000，不在 dialout(18)；设备为 root:dialout 0660，无 user ACL，无 uaccess(udev TAGS=:systemd:)。随后经 pkexec 最小临时 ACL 解决（`pkexec /usr/bin/setfacl -m u:shizuku:rw /dev/ttyUSB0`，exit 0，仅该设备），见 `access-and-flash.txt`；之后串口采集与 sftool verify 刷写均正常。§2 的 PermissionError 是授权前的历史记录。
